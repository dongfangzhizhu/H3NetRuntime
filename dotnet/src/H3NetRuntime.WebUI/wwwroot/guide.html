模型权重下载与安装

MiniMax-H3 / HyperFlow H3 Flash · 本页随 WebUI 一起分发，离线可看

先看这一句：本项目不含权重。整套 ComfyUI_MiniMax-H3-V8 只需要 五个文件（约 49 GB）。文生视频 / 首尾帧用四个；多图参考再多一个 Ref2VA DiT（合计约 65 GB）。不用改名、不用 config.json、 不用 PDD LoRA —— 这些都要归功于 checkpoint 自带的 HyperFlow metadata。

1. 五个文件，按目录放好

最省事的做法：保持 ComfyUI 的 models/ 目录结构不动，WebUI 会自动识别。 把模型目录设为 H3_MODEL_DIR，或在页面的「模型」面板里选。

ComfyUI_MiniMax-H3-V8/ComfyUI/models/
├── diffusion_models/
│   ├── minimax_h3_fl2va_hyperflow_flash_int8_convrot.safetensors   ≈15.9 GB
│   └── minimax_h3_ref2va_hyperflow_flash_int8_convrot.safetensors   ≈16.3 GB
├── text_encoders/
│   └── qwen3vl-32B-MiniMax-H3-Q4_K_M.gguf                          ≈14.6 GB
└── vae/
    ├── minimax_h3_sol_vae_int8_convrot.safetensors                  ≈1.99 GB
    └── minimax_h3_audio_vae_fp32.safetensors                        ≈605 MB
文件必须说明
minimax_h3_fl2va_hyperflow_flash_int8_convrot.safetensors 必须FL2VA DiT，47 个 block；文生视频与首尾帧都用这个
qwen3vl-32B-MiniMax-H3-Q4_K_M.gguf 必须Qwen3-VL 文本编码器，GGUF Q4_K_M
minimax_h3_sol_vae_int8_convrot.safetensors 必须视频 VAE，24 层 decoder.blocks
minimax_h3_audio_vae_fp32.safetensors 必须音频 VAE，归一化参数已折叠进权重
minimax_h3_ref2va_hyperflow_flash_int8_convrot.safetensors 可选Ref2VA DiT，49 个 block；只给「多图参考」用
不需要：config.json、pdd_heads.safetensors、 pdd_lora.safetensors、tokenizer.json。 层数、time embedder 宽度、sigma 表、gate 都从 safetensors 的 __metadata__.hyperflow_int8 读取；tokenizer 已随程序分发。

2. 从哪里下载

文件来自 ComfyUI_MiniMax-H3-V8 整合包所配套的仓库（Hugging Face / ModelScope 搜索上面的完整文件名）。下载前通常需要接受 MiniMax H3 Community License。下载后保持原文件名即可， 本项目的模型定位器按文件名关键字自动匹配。

如果文件散落在别的目录，不必搬动 —— 见第 5 节「逐组件路径」。

3. 校验是否装对

启动 WebUI 时，控制台会打印模型来源目录和每个组件的完整路径： [OK] FL2VA DiT ... F:/models/diffusion_models/minimax_h3_fl2va_...safetensors。 页面顶部也会列出缺失组件。也可以直接问后端：

curl -X POST http://127.0.0.1:7867/api/model/refresh
# {"usable":true,"packDir":".../ComfyUI/models","comfyLayout":true,"ref2va":true,"missing":[]}

命令行只读自检（不需要生成）：

dist\win-x64\h3rt_smoke.exe   （在构建之后）

4. 三种生成模式

模式输入额外权重
t2v 文生视频提示词—
fl2v 首尾帧提示词 + 首帧 / 尾帧—
ref2v 多图参考提示词 + 最多 9 张有序参考图Ref2VA DiT

每种模式都内置了几条示例，点一下就会填入提示词、规格和示例图片， 改两个词就能直接生成。参考图的卡片序号对应提示词里的「参考图 1 / 2 / …」。

5. 权重不想集中放？用逐组件路径

在 appsettings.json 里逐项指定绝对路径，留空的项回落到自动探测结果：

"H3": {
  "Models": {
    "Transformer": "E:/hf/minimax_h3_fl2va_hyperflow_flash_int8_convrot.safetensors",
    "Ref2vaTransformer": "E:/hf/minimax_h3_ref2va_hyperflow_flash_int8_convrot.safetensors",
    "TextEncoder": "E:/hf/qwen3vl-32B-MiniMax-H3-Q4_K_M.gguf",
    "VideoVae": "E:/hf/minimax_h3_sol_vae_int8_convrot.safetensors",
    "AudioVae": "E:/hf/minimax_h3_audio_vae_fp32.safetensors"
  }
}

运行时会用硬链接 / 目录联接（Windows）或符号链接（Linux）拼出引擎认识的标准布局， 不复制权重。缓存目录默认在模型包旁，可用 H3:PackCacheDir 指定。

6. 常见错误

现象原因与处理
「多图参考」模式不可选 没有 minimax_h3_ref2va_... 这个 DiT；其它四个组件与 FL2VA 共用。
cannot open .../config.json 使用了旧版模型包。本项目面向 HyperFlow Flash 五文件，不需要 config.json。
算力 89 ≠ 编译 120 原生库按别的 GPU 编译。用 scripts\build.cmd <算力> 重建，或换对应构建。
去噪异常慢（几十秒一步） 显存被其它进程占满，权重溢出到内存。检查 nvidia-smi。
提示 ffmpeg 相关失败 把 ffmpeg 与 ffprobe 放进 PATH，MP4 封装要用。
